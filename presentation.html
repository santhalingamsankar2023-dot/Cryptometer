Mathematical Architecture

Mathematical Foundations of RSA

Based on the Euler Totient Theorem and the difficulty of integer prime factorization.

1. Key Generation
p, q ∈ Primes
n = p × q (Modulus)
φ(n) = (p - 1)(q - 1)
gcd(e, φ(n)) = 1
d ≡ e⁻¹ (mod φ(n))

Public: (e, n) | Private: (d, n)

2. Encryption
Plaintext Message: m
Condition: 0 ≤ m < n
c = mᵉ mod n

Uses public exponent e to compute ciphertext c.

3. Decryption
Ciphertext Block: c
m = cᵈ mod n
m ≡ (mᵉ)ᵈ ≡ m^(ed) ≡ m

Inversion guaranteed by Euler's Totient Theorem: a^φ(n) ≡ 1 (mod n).

Extended Euclidean Algorithm: Computes modular inverse d = inv(e, φ(n)) such that (e × d) mod φ(n) = 1 in O(log φ(n)) time.

Shannon Entropy Analysis

H(X) = -Σ P(xᵢ) · log₂(P(xᵢ))

Measures randomness in bits per symbol. Plaintext typically scores ~2.8-3.5 bits/char, while encrypted ciphertext approaches ideal diffusion (~3.9-4.0+ bits).

Industry Standard

Hybrid Cryptosystem (AES-256 + RSA)

Combining the speed of symmetric ciphers with the key distribution of asymmetric ciphers.

Digital Envelope Creation (Sender)

  1. Generate a random, single-use 256-bit symmetric session key K.
  2. Encrypt bulk data M with AES-256-GCM using K.
  3. Encrypt only the session key K with the recipient's RSA Public Key (e, n).
  4. Transmit payload: [Encrypted Session Key + Ciphertext + IV + Auth Tag].

Envelope Opening (Recipient)

  1. Decrypt the session key K using the recipient's RSA Private Key (d, n).
  2. Verify authentication tag to prevent tampering (GCM integrity).
  3. Decrypt bulk payload with high-speed hardware-accelerated AES-256-GCM.
  4. Securely discard session key K from memory.
⚡ Performance Advantage: Encrypting a 1 GB file with RSA alone takes hours; with Hybrid AES+RSA it takes less than 0.5 seconds!
